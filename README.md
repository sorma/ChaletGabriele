# Polentoteca Chalet Gabriele - Base Next.js v4

Questa versione include:
- una cartella per ogni pagina con `page.js` e `page.module.css`
- componenti separati per `header`, `nav` e `footer`
- per ogni componente ci sono file JS e CSS dedicati

## Struttura componenti
- `src/components/header/Header.js`
- `src/components/header/Header.module.css`
- `src/components/nav/Nav.js`
- `src/components/nav/Nav.module.css`
- `src/components/footer/Footer.js`
- `src/components/footer/Footer.module.css`

## Avvio
```bash
npm install
npm run dev
```
